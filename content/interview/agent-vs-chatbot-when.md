## 好答案的要点

- **一句话定义讲清增量**：对话机器人是「你问我答」，Agent 是「你给目标，它自己拆任务、调用工具、看结果、再决定下一步」——增量在于规划 + 工具调用 + 循环，而不在于聊得更聪明。
- **判断「值得做成 Agent」的标准**：任务需要多步且步骤间有依赖（查完航班才能排接机）；每步需要外部能力（查库存、调日历、算价格）；过程有反馈可校准（失败了能换路走）。反例：单轮问答套个 Agent 壳，只是把简单问题做贵做慢。
- **主动讲代价，这是成熟度信号**：错误会随步数累积（每步九成五，十几步下来整体成功率骤降）、延迟叠加、成本翻倍、排查更难。所以「能做成 Agent」不等于「该做成」。
- **给产品化的形态**：规划和执行分离、关键动作人确认、失败降级——能报出这些词说明真琢磨过落地。

## 常见的错误答案

- 「Agent 就是更聪明的聊天机器人」——没抓住「调用工具、自己动手」这个本质增量。
- 全程讲概念，说不出一个具体场景的拆解——比如「出差申请」哪几步给 AI、哪几步给系统、哪几步给人。
- 只讲能力不讲代价——把 Agent 当免费的魔法，暴露没碰过真实系统。

## 追问

- 「你手上的需求，哪部分会交给 Agent、哪部分坚决不交？」（考察切分能力：模糊的给模型、确定的给系统、有后果的给人确认。）
- 「Agent 和工作流自动化的区别是什么？」（考察判断：流程固定 → 传统自动化更稳；路径需要动态决定 → Agent 才有价值。）
