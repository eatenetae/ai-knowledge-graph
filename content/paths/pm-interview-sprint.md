## 这条路径怎么走

这条线**只走必修卡**：十五张都是「AI PM 面试前必须掌握」的节点，顺序按依赖关系排布、高频考点优先靠前。它的用法不是通读，是**过考点**：

1. 每张卡先读 L1 和 L2；L3 只在目标岗位明显考这个方向时精读（比如面 RAG 重的产品，`rag` 和 `rag-failure-modes` 的 L3 值得全读）。
2. 每走完一个主题块，去题库里做对应分组的题：**先只看问题，用卡上的知识自己答一遍，再对照「好答案的要点」找差距**——差距就是下一遍要补的。
3. 「常见的错误答案」比要点更值钱：面试里真实出现的坑，提前见过就不会自己跳进去。

## 六个主题块与题库的对应

| 卡片 | 题库分组 | 冲刺要点 |
|---|---|---|
| 1-4 机制 | 能力边界 | 用一句话讲清「它在做什么」，预判它哪里翻车 |
| 5-6 幻觉与度量 | 幻觉与质量 | 机制 + 管理框架 + 事故排查的时序 |
| 7-10 方案 | RAG 与知识库 | 什么时候用什么方案，效果不好怎么分诊 |
| 11-12 Agent | Agent | 与聊天机器人的区别、安全边界、失败兜底 |
| 13 红线 | 数据与安全 | 提示注入为什么是产品级风险 |
| 14-15 成本 | 成本与延迟 | 延迟的根源、token 的账怎么算 |

**项目与协作**那组行为题没有对应的卡片——它们靠案例库和 STAR 框架准备：挑两三个案例库里的决策复盘，按情境-任务-行动-结果四段拆成自己的故事，比背题有效得多。

## 这条线刻意跳过什么

只走必修卡意味着跳过全部机制深水区：`transformer`、`attention`、`neural-network` 这条「它内部长什么样」的线，以及 `vector-database`、`kv-cache` 这类工程细节。这不是疏漏——面试答到判断层就够了，内部构造是系统课和对应节点 L3 的事。个别卡片会引用这些被跳过的机制，读的时候把引用当「进阶入口」而不是「前置欠债」即可。

## 建议节奏

- **标准版（一至两周）**：每天一个主题块，卡片加题目半天以内；最后两天留给案例的 STAR 化和模拟问答。
- **压缩版（两三天）**：只读 L1 + 高频题的要点；卡片里如果只能记一句话，记每张卡 note 里的那句。

## 走完之后

你应该能接住这些追问而不慌：

- 「为什么会一本正经地胡说」——机制一句话，然后是管理的三板斧；
- 「记住所有对话的需求怎么评估」——上限、成本、分层方案；
- 「RAG 和微调怎么选」——知识还是行为，加上「先改提示词」这个默认第一步；
- 「Agent 敢不敢让它自动下单」——按后果分级的权限设计；
- 「怎么向老板证明质量达标」——评测集、门槛、灰度。
