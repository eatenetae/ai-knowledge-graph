## 直觉

机器学习最贵的从来不是算力，是**标注**。

想让模型学会识别垃圾邮件，你得先找人标十万封邮件——一小时几十块，标错还得返工。这是「监督学习（supervised learning）」的死穴：**每多要一点能力，就多要一批人工。**

自监督学习（self-supervised learning）绕开了这件事：**答案不用人给，从数据本身就能造出来。**

具体做法很朴素：拿一句话，把后半截遮住，让模型猜。答案是现成的——就是原文。**不需要任何人标注，互联网上的每一段文字都是一个免费的训练样本。**

为什么这是大模型能出现的根本原因：数据规模从「百万级人工标注」直接跳到「万亿级网页文本」，中间差了六个数量级。没有这一步，「大」模型无从谈起。

一个类比：**做完形填空学外语**。老师不必逐句给你讲解语法，只把文章挖空让你填。填错了对照原文就知道错在哪。**一万篇文章就是一万套免费习题**，而且习题和答案一起送到，不用额外备课。

## 细节

**关键机制**

- **三种常见的自监督任务**：
  - **自回归（autoregressive）**：遮住右边，用前文猜下一个词。GPT 系列用这个，天然适合生成。
  - **掩码重建（masked）**：随机挖掉中间 15% 的词，用两边一起猜。BERT 用这个，天然适合理解，但**不能直接用来生成**——因为训练时它见过右边。
  - **对比学习（contrastive）**：让同一个东西的两个「视角」在向量空间里靠近，不同的推远。图像领域（SimCLR）和文本检索模型（如 Sentence-BERT）用这个。
- **为什么它「免费」但代价不小**：
  - 免费的是标注，不免费的是**算力**。自监督的样本利用率比监督学习低——模型要看过海量文本才能提炼出规律。
  - 学到的能力也**不精确**：模型会知道「巴黎是法国的首都」，但不会知道「用户问的时候要简洁回答」。前者是**知识**，后者是**行为**——行为得靠后训练（`instruction-tuning`、`rlhf`）来教。
- **和半监督、无监督的区别**（这三个词经常被混用）：
  - **无监督**：没有标签，目标是找结构（比如聚类）。
  - **自监督**：没有人工标签，但**自己造标签**，目标仍是预测。自监督是无监督的一种，但它是「有监督目标的无监督数据」。
  - **半监督**：少量标注 + 大量未标注混着用。

**它改变了什么**

在自监督之前，NLP 的范式是「一个任务一个模型一份标注数据」。之后变成了「**先在海量无标注文本上学一个通用底座，再针对具体任务微调**」。这个「预训练 + 微调」范式就是今天所有大模型的工作方式——预训练之所以可能，正是因为自监督。

**可运行代码**

```python
# 自监督的关键：标签是从输入自己切出来的，不需要外部标注
import torch

text = torch.tensor([10, 25, 7, 88, 42, 13, 61, 9])   # 一段 token 序列

# 自回归：输入 = 前 n-1 个，标签 = 后 n-1 个（错开一位）
x = text[:-1]          # [10, 25, 7, 88, 42, 13, 61]
y = text[1:]           # [25,  7, 88, 42, 13, 61,  9]
print("输入:", x.tolist())
print("标签:", y.tolist())          # 标签就是输入往后挪一位 —— 零人工成本

# 掩码重建：随机挖洞，标签是被挖掉的那些词
mask = torch.rand(len(text)) < 0.25
masked = text.clone()
masked[mask] = 0                    # 0 当作 [MASK]
print("挖洞后:", masked.tolist())
print("要猜的:", text[mask].tolist())   # 答案仍然来自原文

# 两种做法的差别只有一处：能看右边，还是只能看左边
```
