## 直觉

「让模型变好」这句话必须先翻译成一句机器能听懂的话：**好，到底是多少分？**

损失函数（loss function）就是这个打分公式。它拿模型的输出和正确答案比一比，吐出一个数字：**越小说明越接近正确答案**。有了这个数字，训练才有了方向——不是「往好的方向改」，而是「往让这个数字变小的方向改」。

为什么它是整个训练的地基：**损失函数选错了，模型会非常认真地学成一个你不想要的东西。** 想让模型回答准确，却用「回答长度」当损失，它就会学着把话说得又长又漂亮，而不管对不对。模型没有价值观，它只优化你写下的那个公式。

一个类比：**考试的评分标准**。学生（模型）不知道什么叫「好」，他只知道怎么拿高分。评分标准写「字迹工整加十分」，他就会去练字——哪怕答案全错。**你考核什么，就得到什么。**

## 细节

**关键机制**

- **训练循环就四步**，损失函数在第二步：
  1. **前向**：把数据喂进去，拿到预测；
  2. **算损失**：`loss = 损失函数(预测, 正确答案)`；
  3. **反向**：自动微分求出「每个参数往哪动能让 loss 变小」（梯度）；
  4. **更新**：按学习率把参数往梯度反方向挪一小步。
- **交叉熵（cross-entropy）是大模型的默认选择**。它衡量「模型给正确答案分配的概率有多低」——正确答案概率越接近 1，损失越接近 0。语言模型每一轮就是一次巨大的交叉熵：词表里几万个候选，正确答案是那个真实的词。
- **损失曲线的读法**：
  - 训练损失降、验证损失也降 → 正常在学习；
  - 训练损失降、验证损失开始上升 → **过拟合**，模型在背题；
  - 损失变成 `NaN` → 学习率太大或数值溢出，先把学习率调小一个数量级。
- **困惑度（perplexity）**：交叉熵的指数形式，语言模型最常用的指标。困惑度 20 大致可以理解为「模型在每一步平均在 20 个候选里犹豫」。它和人读起来顺不顺的相关性，比准确率这类指标高得多。

**为什么不用「答对率」当损失**

因为答对率是**离散的**：从 99% 对变成 100% 对，中间没有连续变化。梯度下降需要「稍微好一点点」这种连续信号才能知道往哪走。交叉熵的好处正是它**连续可导**——模型把正确答案的概率从 0.01 提到 0.02，损失就真的下降了一点，方向就有了。

**可运行代码**

```python
import torch, torch.nn.functional as F

# 三个样本，词表 5 个候选，模型给出的分数（logits）
logits = torch.tensor([
    [2.0, 0.5, 0.1, 0.2, 0.1],   # 模型很确信是第 0 类
    [0.1, 0.2, 0.1, 3.0, 0.1],   # 很确信是第 3 类
    [0.3, 0.3, 0.3, 0.3, 0.3],   # 完全没主意，五类平分
])
target = torch.tensor([0, 3, 2])   # 正确答案

loss = F.cross_entropy(logits, target, reduction="none")
print(loss)              # 前两个接近 0（答对了），第三个明显大（在瞎猜）
print(loss.mean())       # 训练时用的就是这个标量

print("困惑度:", torch.exp(loss.mean()).item())
```

把 `target` 改成 `torch.tensor([0, 3, 0])`（第三个样本故意给个错的答案），你会看到第三个损失飙升——**这就是「模型被惩罚」的样子，也是它学习的唯一信号来源。**
