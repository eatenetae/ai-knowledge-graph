## 直觉

传统程序是「人写规则，机器照着做」。想识别垃圾邮件，你得手写一堆 if：包含「中奖」就扣分、发件人在黑名单就扣分……规则越写越多，骗子稍微改个词就失效了。

机器学习换了个方向：**人给例子，机器自己总结规则**。给它十万封已经标好「垃圾/正常」的邮件，它自己去找哪些特征有用。你不再需要知道「中奖」这个词是关键——它自己会发现。

为什么重要：凡是「规则很难写清楚、但例子很容易找」的问题，机器学习都能用。识别猫、翻译句子、预测房价、判断一句话的情绪，都是这一类。反过来，如果规则本来就很清楚（比如算个税），用机器学习反而是绕远路。

一个类比：传统编程像**手把手教做菜**，每一步都要写清楚；机器学习像**让人尝一万道菜后自己学会调味**——你说不清那个「手感」，但他就是学会了。

## 细节

**关键机制**

- 三要素：**数据**（例子）、**模型**（一套可调参数的函数）、**目标**（衡量输出好坏的分数）。
- 训练 = 不断调整参数，让目标分数变好。最常见的手段是**梯度下降**：算出「参数往哪个方向动能让错误变小」，然后往那个方向挪一小步，重复几百万次。
- 两类主要范式：**监督学习**（例子带标准答案）、**无监督学习**（只有例子没有答案，让模型自己找结构）。大语言模型属于**自监督**——答案就藏在文本本身（用前文预测下一个词），所以不需要人工标注，这是它能吃下整个互联网的关键。

**常见误区**

- 机器学习不是「让机器产生意识」，它只是在做函数拟合。
- 数据质量比模型花哨程度重要得多。垃圾进，垃圾出。
- 模型在训练数据上表现好不代表有用，它可能只是**背下来**了（过拟合）。

**可运行代码**

一个最小的监督学习例子（线性回归），二十行就能看清「训练」到底在干什么：

```python
import numpy as np

# 造数据：真实规律是 y = 3x + 2，加一点噪声
rng = np.random.default_rng(0)
x = rng.uniform(-1, 1, size=(200, 1))
y = 3 * x + 2 + rng.normal(0, 0.1, size=(200, 1))

w, b = 0.0, 0.0          # 待学参数
lr = 0.1                 # 学习率：每步挪多大
for step in range(200):
    pred = x * w + b
    error = pred - y
    # 对 w 和 b 分别求「错误对参数」的偏导
    grad_w = 2 * (error * x).mean()
    grad_b = 2 * error.mean()
    w -= lr * grad_w
    b -= lr * grad_b

print(f"学到的规律: y = {w:.3f}x + {b:.3f}")   # 接近 y = 3x + 2
```

这段代码就是所有深度学习的骨架：**预测 → 算误差 → 求梯度 → 更新参数**。大模型只是把 `x * w + b` 换成了几千亿个参数的复杂函数。
